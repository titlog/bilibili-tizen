## 约定

`app/js/` 是包在 IIFE 里的纯 ES5，没有构建步骤。`tools/` 是 Node ESM，用现代
语法没问题。

> **这台设备不是本文档以前声称的那样。** 它报告
> `Tizen 9.0 … Chromium 120.0.6099.5`，ES6、MSE、Blob URL、Promise、fetch 一应
> 俱全 —— 出厂之后升级过。ES5 风格现在是**约定**而不是**约束**，「引擎太老所以
> 不能用 X」这个论据对任何事情都不再成立。每个构建启动时都会上报引擎字符串，
> **先读它，再做假设。**
>
> **⟶ 2026-10-18 起这句只对这台成立。** `required_version` 降到 5.5（PR #2，Q90T 上实测的
> 兼容部分），最老要跑在 Chromium 69 上，ES5 又成了约束；CSS 也一样 —— Chromium 69 没有
> flex 布局的 `gap`。`js/compat.js` 实测有没有它，没有就给 `<html>` 加 `legacy-flex-gap`，
> 由 `css/legacy-layout.css` 用 margin 和 grid-gap 顶替。**`app.css` 里每加一个带 `gap`
> 的 flex 容器，都要在 `legacy-layout.css` 里补一条**，否则老电视上子元素会挤在一起，
> 而在这台电视上什么都看不出来。
>
> **⟶ 2026-10-20 再降到 3.0**（issue #4、#5：2017/2018 年的电视连装都装不上，有人手改
> 版本号装过）。最老的引擎变成 **Chromium 47**（Tizen 3.0；4.0 是 56、5.0 是 63）：没有
> CSS 变量（49）、没有 CSS grid（57）、sloppy 模式下没有 `let`（49）。`app/js` 当时扫过一遍，
> 全是 ES5，只用到 Promise、`Element.animate`、`crypto.subtle` 这类 47 就有的；`app.css`
> 没有 `var(--`（`style.css` 有，但那是 spike 留下的、`index.html` 不加载）。没有 grid 的
> 引擎上 `compat.js` 再加一个 `legacy-no-grid`，卡片网格改用 margin（桌面上手动加这两个类，
> 三种每行密度下卡片位置和现代布局逐像素一致）。Shaka 4.12.5 自带 Tizen 2/3/4 的 MSE 补丁。
> **两代都没在真机上播过**，`engine:` 行末的 `布局=` 说这台走的是哪套。

唯一的依赖是 `app/vendor/shaka-player.compiled.js`，以预编译包的形式入库。它不
需要打包工具，而且它本身就是 ES5。

**提示在屏幕正中（2026-10-20：文字提示放在屏幕下方，有时候注意不到）**：番剧地区
限制那句就是在屏幕下方被错过的。`#toast` 现在居中、字大一号、在面板和侧栏之上，四秒后消失。

**屏幕上的字只给观众要用的信息（2026-09-28）。** 「从 08:46 继续播放」「接着手机上的进度」
「从 P7 继续」这类提示删掉了 —— 画面从 8:46 起来本身就是通知，位置从哪台设备来是写代码的人
关心的事，对观众是理解负担。它们改进日志（`从 8:46 起播（手机上的进度）`、`续播选 P7`）。
**留下的三类有它们的理由**：打不开时的原因（不说就是无声地被退回首页）、自救时的
「网络不顺，正在自动重试…」（没有它十几秒黑屏读起来像死机，观众会退出重开、打断正在
成功的自救）。**「正在打开…」10-18 拿掉了**（点开视频时不该在画面下方挂着它）：它是给
不带 cid 的卡片（搜索、动态、UP 主页、收藏夹）问 view 那几百毫秒用的，可 toast 要挂满 4 秒，视频出来了
它还压在画面底下。现在按下确认就直接进播放的加载画面（卡片标题 + 转圈，`showOpening`），和带 cid 的卡片
一样；等 view 期间按键不落到后面的网格，返回键回网格。加新提示之前先问：观众看了会做出
不同的事吗？不会，就进日志。

一切由 D-pad 驱动：方向键移动焦点，中键选中，返回键后退。焦点是几何的 ——
`nav.js` 挑出位于按下方向上、距离最近的那个 `.focusable` —— 所以参差不齐的网格
不需要任何人声明列数就能工作。**新加的东西必须能这样够到，这里没有指针。**
横向移动**同一行优先，纵向同一列优先**（矩形在垂直/水平方向重叠算同行/同列），
同行没有候选才退回纯几何评分（2026-08-21）——这不是可以省掉的偏好：分P切片按
文字定宽，宽切片右邻居的**中心**能在五百像素外，而下一行只在九十像素下面，纯
中心距评分曾让面板里的「右」落进下一行。均匀网格撞不到（正下方卡片被方向过滤
器挡掉），所以这个 bug 只在切片那一行现形；自测「面板里按右键走的是同一行」
盯着它。
